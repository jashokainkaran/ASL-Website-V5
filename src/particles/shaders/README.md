# Mutable Matter shader responsibilities

`particle.ts` generates registry-driven progressive curved morphs. Position is evaluated twice for restrained velocity stretch. Packed identity/character attributes drive size variation, focal softness, shimmer, mass and warm colour. The canonical hero only uses filaments, cloud, spatial DNA and the ASL mark; emergence uses the roaming target. Two lazy section buffers hold the newer capability forms.

`pointer.ts` projects the current undeformed formation into CSS-pixel screen coordinates, combines eight bounded input impulses, and applies displacement in camera view space. Depth-aware conversion keeps the visible radius consistent across overlapping Z planes. Critically damped temporal decay heals the current target, while mass variation prevents a uniform displaced rim. Formation attributes are never mutated. The previous separate luminous cursor ribbon has been removed.

Main sprites use an antialiased central core and a low-energy shoulder. Additive core overlap supplies luminosity in dense regions. Density-response tuning adjusts the energy of those overlaps, not a measured GPU neighbourhood-density field. No bloom, framebuffer density pass or per-particle CPU updates are introduced. Ambient rendering remains separate and subordinate.
