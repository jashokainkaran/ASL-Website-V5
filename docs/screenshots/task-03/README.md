# Task 03 visual evidence

Final viewport captures use production at 3003. The corrected `1440-handoff.png` and final mobile-menu capture use development with only development overlays hidden. `baseline` and `pass-*` are iterative evidence, not final comparisons. All are viewport images because one persistent canvas cannot represent every state in a full-page capture.

Widths: 1920x1080, 1440x900, 1366x768, 768x1024, 390x844. Each final width includes hero, lattice/Design, strata/Development, stream/Deployment, cluster/Digital Products, statement and final conversion.

`1440-initial` proves the unobstructed homepage. `loader-early`, `loader-forming`, `loader-settled` are computed animation stages with a paused browser clock (approximately 180/660/1000ms) and CSS safety cutoff disabled only for capture. The real cutoff and total duration were tested separately. `inner-post-loader` shows released content. Reduced and no-WebGL files include home and direct-entry identity; `390-menu` records the disclosure.

Motion verification: real scrolling sampled progressive/reversed phrase transforms; route convergence sampled every 20ms; canvas identity checked across client navigation; loader visibility timing measured live on entry and refresh; reduced-motion captures compared 500ms apart; CTA transform checked at hover and after exit. See the report for values and limitations. Stills do not prove subjective smoothness or device GPU performance.
