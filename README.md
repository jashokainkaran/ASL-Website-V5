# ASL — Mutable Matter

A Next.js landing page with a persistent, shader-driven particle world.

## Run

- `pnpm install --frozen-lockfile`
- `pnpm dev` — http://localhost:3000
- `pnpm lint` and `pnpm typecheck`
- `pnpm build` then `pnpm start` — production

The development-only Leva panel exposes progress, tiers, particle character, formations and pointer controls. Expand Scene measurements for projected bounds and sampled FPS. `/lab/mutable-matter` remains available for engine review.

Set `NEXT_PUBLIC_SITE_URL` in the deployment environment before building. Booking is intentionally not connected; the canonical CTA URL lives in `src/content/site.ts`. Work, About and Contact retain honest placeholder content pending confirmed business details. Proof entries and the provisional identity are explicitly marked.

Read `AGENTS.md`, `docs/ASL_BRAND_AND_STORY.md` and the three task reports before extending the system. Screenshot evidence is in `docs/screenshots/task-01/` and `docs/screenshots/task-02/`. Automated FPS is not representative of real-device performance.
